# Local Setup

To preview the project locally, install the dependencies and run the development server.

---

## Running a Local Server

#### Prerequisites

Make sure [Node.js](https://nodejs.org/) is installed on your system, along with NPM.

#### Setup

1. Open the terminal and navigate to the project's root folder.
2. Run `npm install` and wait for it to finish.
3. Run `npm run dev`.
4. Now open [localhost:4444](http://localhost:4444) in your browser to view the project.
